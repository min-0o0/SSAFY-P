01

알 수 없는 검은 창, CLI의 두려움

SSAFY에 처음 들어와 마주한 터미널 창. 마우스 클릭도 없이 오직 키보드만으로 폴더를 탐색하고 파일을 옮겨야 하는 CLI 환경은 마냥 낯설고 조심스럽기만 합니다.

02

암기식 Git 명령어의 한계

git add ., git commit -m, git push만 번갈아 기입하다 마주하는 Merge Conflict. 원리조차 모르다 보니 무서워 --force 플래그를 붙이고 말았던 아찔한 경험을 딛고 가야 합니다.

03

원리를 시각적으로 꿰뚫는 순간

로컬 저장소의 3대 구역을 머릿속에 그림으로 그려낼 수 있다면, 어떤 Conflict가 발생해도 침착하게 히스토리를 정렬하고 협업의 중심으로 나아갈 수 있습니다.

내부의 3단계 흐름 시각화

로컬 폴더에서 수정한 코드가 어떤 경로를 통해 박제에 이르기까지 저장되는지, 징검다리 3대 영역을 명료하게 구조화해 이해를 도우며 불완전한 상태 정렬을 방지합니다.

01 / VISUALIZATION

게임처럼 즐거운 퀘스트 달성

스토리 라인을 따라 진행되는 점진적인 난이도와 직관적인 알림, 보상 시스템을 통해, CLI 사용법을 오락 게임을 클리어하는 것 같은 자연스럽고 다정한 성취감으로 바꿉니다.

02 / INTERACTIVITY

동작 방식의 본질적 통찰

가지치기와 같은 복잡한 병렬 브랜치 개발 모델을 눈으로 직접 보며 손가락으로 가볍게 실시간 변화를 주입해 보아, 팀 프로젝트 시 협업 효율과 수평적 커뮤니케이션을 가속시킵니다.
